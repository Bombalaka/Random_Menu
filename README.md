# 📱 RandomMenu - Random Food Generator

Never wonder "What should I eat?" again - just tap and get instant random suggestions. 
##### Built with: AWS Cloud Services • React Native • AI-Powered Food Discovery

## The Problem
People spend too much time thinking about what to eat every day. This causes:
- Decision fatigue 
- Wasted time

**Solution:** A simple app that picks random foods from your favorites, so you don't have to think.
## 💡 What I Built

A complete **cloud-based mobile application** consisting of:

- **Mobile App** (Android) - User-friendly interface for meal planning
- **9 lambda Functions** - Intelligent backend processing in the cloud
- **AI Integration** - Artificial intelligence for personalized food suggestions
- **Database System** - Secure storage for user preferences
- **REST API** - Professional communication between app and cloud

**Scale:** Handles unlimited users with automatic scaling and costs less than $1/month to run.

## ✨ Key Features

### For Users:

- 🎲 **Instant Menu Generation** - Get a complete day's meal plan in seconds
- 🤖 **AI Food Suggestions** - Discover new foods based on your taste preferences
- 📝 **Personal Food Library** - Save and manage your favorite meals
- 🔒 **No Passwords Required** - Secure device-based access
- 📱 **Works Everywhere** - Android support

### Technical Highlights:

- **Serverless Architecture** - Zero server maintenance, automatic scaling
- **AI-Powered** - Uses Claude AI (Anthropic) for intelligent suggestions
- **Cloud-Native** - Built entirely on Amazon Web Services (AWS)
- **Cost-Efficient** - Pay-per-use pricing model
